# Sitio web de SEDIPRO UNT

Somos la **Sección Estudiantil de Dirección de Proyectos de la Universidad Nacional de Trujillo**, un equipo multidisciplinario que forma futuros líderes mediante las buenas prácticas de gestión de proyectos, la metodología PMI y herramientas ágiles, con un enfoque académico, social y ambiental.

Desde el **área de Tecnologías de la Información (TI)** desarrollamos y mantenemos este sitio web para conectar a nuestra comunidad y apoyar las iniciativas de SEDIPRO UNT. Contribuimos a su visión de ser la mejor SEDIPRO a nivel nacional mediante soluciones digitales que impulsan la colaboración y el impacto positivo.
